# Ideias opcionais de sensores

As propostas foram consolidadas no [roadmap](roadmap.md#futuro), junto das
dependências e prioridades. BMP390, QMC5883L, GNSS e pitot/pressão diferencial
continuam possibilidades futuras, não hardware implementado.

O projeto atual usa BMP085 e HMC5883L. QMC5883L exige outro driver; velocidade
inercial estimada não é airspeed. Consulte [sensores](sensores.md) para o estado
real e [VGA auxiliar](vga_auxiliar.md) para a expansão de vídeo.
